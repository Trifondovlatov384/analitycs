# Deals dashboard (local)

Локальный интерактивный дашборд по сделкам из `august2026.csv` (экспорт bnMAP по Крыму; при необходимости можно подставить свой CSV).

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть в браузере: `http://127.0.0.1:8050`

Оболочка (`public/`) отдаётся сразу, графики и KPI подгружаются параллельно через `/api/*`.

## Скрытые разделы

В меню видны: Дашборд, Комплексы, Сравнение, Эйлер, Теплокарта.

**ЕГРЗ** скрыт из меню, но открывается по прямой ссылке без ключа:

- `http://127.0.0.1:8050/?tab=tab_egrz`

**Рост лота** и **Рост проектов** тоже скрыты из меню и открываются только с ключом доступа.

Задайте ключ. Локально по умолчанию работает `dev-admin-key`, на Vercel без переменной `ADMIN_ACCESS_KEY` эти разделы закрыты:

```bash
export ADMIN_ACCESS_KEY="ваш-секретный-ключ"
python app.py
```

Прямые ссылки (подставьте свой ключ и хост):

- `http://127.0.0.1:8050/?access=ваш-секретный-ключ&tab=tab_lot_growth`
- `http://127.0.0.1:8050/?access=ваш-секретный-ключ&tab=tab_project_growth`

Без правильного `access` эти два раздела не откроются.

## Доступ

Логины и пароли в коде не хранятся. Задайте их переменной окружения (на Vercel — Settings → Environment Variables):

```bash
export DASH_AUTH_USERS="login1:pass1,login2:pass2"
export FLASK_SECRET_KEY="длинная-случайная-строка"
```

После 10 неудачных попыток входа с одного IP вход блокируется на 15 минут.

## Данные

Основной источник — выгрузки bnMAP «Сделки» по регионам. Файл кладётся в корень проекта с исходным именем,
например `bnMAP_pro_Сделки_Краснодарский_край_19-10-2026.csv` или `bnMAP_pro_Сделки_Республика_Крым_….csv`.
Регион определяется по имени файла (Крым, Краснодарский край, Адыгея и др.). Если по региону лежит несколько
выгрузок, они объединяются, а одна и та же сделка (лот + дата + тип договора) считается один раз.

Когда в проекте есть выгрузка bnMAP по Краснодарскому краю, старые `Analitic.csv` и `KK2026.csv` не загружаются:
это те же сделки за более короткий период.

Чтобы не тащить в репозиторий персональные данные и лишние колонки, перед добавлением оставьте только нужные
столбцы (список — `BNMAP_USE_COLS` в `data_loader.py`).

После пуша нового CSV GitHub Actions сам пересобирает `data/cache/combined_deals.parquet`, и Vercel выкладывает
обновлённые данные. Локально кэш пересобирается командой `python scripts/build_deals_cache.py`.

По умолчанию машино-места и кладовки в расчётах не участвуют. Чтобы их посмотреть, выберите их в фильтре «Тип».

## Деплой на Vercel

Проект настроен для Vercel через `api/index.py` и `vercel.json`.

1. Запушьте код в GitHub.
2. В Vercel: **Add New Project** -> выберите репозиторий.
3. Framework Preset: **Other**.
4. Root Directory: `/` (по умолчанию).
5. Нажмите Deploy.
